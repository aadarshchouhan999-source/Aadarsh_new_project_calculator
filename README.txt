SMART CALCULATOR - BCA COLLEGE PROJECT

PROJECT OVERVIEW
Smart Calculator is a beginner-friendly web application that performs basic arithmetic calculations.

TECHNOLOGIES USED
1. HTML - creates the structure of the calculator.
2. CSS - provides the layout, colours and responsive design.
3. JavaScript - handles button clicks, keyboard input and calculations.

FEATURES
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal calculations
- Clear (AC) and Delete (DEL)
- Keyboard support
- Error message for invalid calculations
- Responsive layout for mobile and desktop

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The calculator will open in your web browser.
   No installation or internet connection is required.

PROJECT FILES
- index.html : Main webpage
- style.css  : Design and styling
- script.js  : Calculator logic
- README.txt : Project instructions
